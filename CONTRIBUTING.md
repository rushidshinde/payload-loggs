# Contributing to Payload Loggs

👋 Thank you for your interest in contributing to **Payload Loggs**!
Your contributions help make this plugin more useful, secure, and stable for the Payload CMS community.

---

## 🧩 Development Setup

To develop, you need to follow these steps:

- Click the **Fork** button on GitHub to create your own copy.

- Clone your fork locally

```bash
git clone https://github.com/<your-username>/payload-loggs.git
cd payload-loggs
```

* Install dependencies

```bash
pnpm install
```

* Connect to the main repo (Just once):

```bash
git remote add upstream https://github.com/rushidshinde/payload-loggs.git
```

* Create a Branch:

```bash
git checkout -b feat/my-new-feature
```

* Write code & commit using Conventional Commits

```bash
pnpm commit
```

* Open a Pull Request: Open a PR to the main branch of `rushidshinde/payload-loggs`.

---

## 🧪 Plugin testing environment

You can test your changes locally in the dev workspace:

```bash
pnpm --dir ./dev dev
```

---

## 📬 Contact

If you have any questions or want to discuss an idea before coding:

- Open an [Issue](https://github.com/rushidshinde/payload-loggs/issues)
